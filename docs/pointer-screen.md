# 鼠标所在屏幕模式

## 使用

设置和菜单栏均可选择三种互斥的显示模式：始终显示全部通道、靠近边缘时显示全部通道、仅鼠标所在屏幕显示。第三种模式在鼠标所在屏幕显示该屏幕已有的全部通道，不要求靠近边缘；鼠标静止也不会超时隐藏。扩展屏、通用控制通道和手动标记使用同一筛选规则，不新增不存在的通道。

通用控制两端需分别安装新版并选择第三种模式。每台 Mac 独立读取本机状态，无需配对或网络通信。现有 v1.3.0 发布包不包含此功能。

## 读取和限制

- 每约 80 毫秒读取 `NSEvent.mouseLocation` 和 `CGCursorIsVisible`。只更新现有窗口的透明度，不重建窗口或查询通用控制服务；无需辅助功能、输入监控或屏幕录制权限。
- `CGCursorIsVisible` 的返回类型按 SDK 中的 `boolean_t` 处理。该只读函数已弃用，通过动态加载处理不可用情况；不可用或光标不可见时不使用残留坐标显示提示线，设置会说明接口不可用。
- 可见性不是通用控制的独立设备所有权接口。打字、全屏视频或其他应用主动隐藏光标时，也会隐藏提示线；再次显示光标后恢复。不通过静止超时或最后一次输入猜测鼠标归属。
- 坐标采用本机实际屏幕排列，处理负原点、共享边界和空隙；镜像副屏属于同一桌面，无法从镜像画面中单独隐藏提示线。
- 锁屏仍遵循鼠标所在屏幕筛选，锁屏常显选项只覆盖靠近显示模式。预览按钮仍临时展示所有本机屏幕的示例线。
- 原配置的 `nearOnly` 迁移为对应模式，保留粗细、手动标记和其他开关；保存时保留旧字段，便于旧版读取。新安装默认仍为全部常显。
