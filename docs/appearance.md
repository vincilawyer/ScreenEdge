# 边缘外观

1.5.0 为扩展屏和通用控制各自保存 `EdgeAppearance`：材质、渐变预设、单色、自定义渐变起止色和不透明度。手动补充标记沿用通用控制外观，不代表已连接。两台 Mac 不交换设置。

## 绘制与保存

- `Preferences.extendedAppearance / universalAppearance` 按通道来源选择。旧配置缺少字段时保留原海岸 / 日落渐变及 100% 不透明度；新安装使用霜白 / 雾蓝毛玻璃及 80% 不透明度。
- `EdgeStripView` 统一用于实际覆盖层和设置示例；`EdgePaintView` 绘制渐变、纯色或毛玻璃着色。渐变纵向从上到下、横向从左到右，覆盖实际通道范围。不同配色不会改变坐标、通道长度或显示模式。
- 毛玻璃使用 `NSVisualEffectView`、`.underWindowBackground`、`.active`。实际边缘使用 `.behindWindow`，设置示例使用 `.withinWindow`；细线有圆角和轻微亮边，无窗口阴影。样式透明度在内容视图上，鼠标归属控制窗口透明度，两者分开，避免定时刷新把用户选择恢复成全不透明。
- 系统“减少透明度”开启时隐藏模糊层，绘制不透明背景和着色；通过系统通知即时刷新，不修改系统辅助功能设置。切回渐变或纯色时隐藏模糊层。
- 颜色持久化为 sRGB 分量，不保存 NSColor 私有对象；输入范围限制在 0–1，不透明度限制在 15%–100%。损坏的新外观字段独立回退，不丢失其他偏好。切换材质时保留各自颜色，恢复默认仅修改选中的一类通道。
- 自选颜色按钮使用轻量圆角色块，通过 NSColorWell 接收系统颜色面板的变化；页面销毁或切换编辑目标时解除面板关联。按钮打开、颜色回调和解除关联已经使用本进程临时界面验证。
- 所有覆盖窗口仍鼠标穿透、不可激活，且不扩大到实际边缘外。界面上的 4 秒预览在每块本机屏幕左侧画扩展屏样式、右侧画通用控制样式；不产生真实通道。

采用系统模糊材质的依据见 [Apple NSVisualEffectView](https://developer.apple.com/documentation/appkit/nsvisualeffectview) 和 [Apple 材质设计说明](https://developer.apple.com/design/human-interface-guidelines/materials)。这里使用兼容 macOS 13+ 的 AppKit 材质，不声称实现 macOS 26 Liquid Glass。

## 验证边界

纯逻辑检查覆盖迁移、独立保存、通道分配、自定义色和无效值回退。`--smoke-test` 检查所有渐变在不同长度与方向下的像素、纯色像素、原生模糊层、透明度、切换材质、模拟减少透明度，以及模拟锁屏后样式保留；合成通道还验证三种材质在鼠标隐藏/返回时保留自身不透明度。`--settings-snapshots` 使用临时配置输出三种材质与浅深色界面，不采集桌面。本轮 `--uc-check` 没有实际通道，返回 INCONCLUSIVE / 2。

检查通过不等同于所有背景上的实际观感验收。原生毛玻璃在 2–8 点宽的边缘上效果较轻，受背景、系统合成与辅助功能设置影响。实际锁屏画面的模糊效果尚未单独实测；已有锁屏提示可用不等同于新材质也完成真实锁屏验收。两台新版 Mac 的出入口颜色对应需要在相同配色下双端验证。
