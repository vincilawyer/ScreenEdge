# 边缘样式

1.5.0 / 7 将粗细、配色和不透明度集中在“边缘样式”页；“边缘显示”页只负责何时显示。扩展屏和通用控制各自保存渐变/纯色、颜色和不透明度，粗细仍是两类通道共用的一个设置。手动标记沿用通用控制配色，不代表已连接。两台 Mac 不交换设置。

## 绘制与保存

- `Preferences.extendedAppearance / universalAppearance` 按通道来源选择。更早的配置缺少字段时保留原海岸 / 日落渐变及 100% 不透明度；新安装使用霜白 / 雾蓝纯色及 80% 不透明度。
- 已移除毛玻璃选项与模糊绘制。解码旧 `material: "glass"` 时改为 `solid`，保留原颜色、不透明度和其他偏好；下次保存不再写出旧材质值。
- `EdgeStripView` 统一用于实际覆盖层和设置示例；`EdgePaintView` 绘制所选渐变或纯色。渐变纵向从上到下、横向从左到右，覆盖实际通道范围。配色不会改变通道坐标、长度或显示模式。
- 样式透明度在内容视图上，鼠标归属控制窗口透明度，两者分开，避免定时刷新把用户选择恢复成全不透明。
- 颜色持久化为 sRGB 分量，范围限制在 0–1；不透明度为 15%–100%。损坏外观字段独立回退，不丢失其他偏好。切换配色方式保留各自颜色，恢复默认仅修改选中的一类配色，不重置共用粗细。
- 自选颜色按钮使用圆角色块，通过 NSColorWell 接收系统颜色面板变化；切换编辑目标时解除面板关联。按钮打开、颜色回调和解除关联已使用本进程临时界面验证。
- 覆盖窗口仍鼠标穿透、不可激活，不扩大到实际边缘外。4 秒预览在每块本机屏幕左侧画扩展屏样式、右侧画通用控制样式；不产生真实通道。

## 验证边界

138 项逻辑与配置检查包括独立保存、通道分配、自定义色、无效值回退及旧毛玻璃迁移。`--smoke-test` 验证各渐变的长度/方向像素、纯色像素、不透明度、配色切换与模拟锁屏后的样式保留；合成通道还验证鼠标隐藏/返回不重置样式透明度。`--settings-snapshots` 输出 16 张设置视图，覆盖粗细、两种配色、浅深色和最小窗口，不采集桌面。

此前 1.5.0 的实际通用控制查询无活动通道，返回 INCONCLUSIVE / 2。两台新版 Mac 的出入口颜色对应仍需在相同配色下双端验证；原有锁屏提示可用，也不代表新配色已经过双端真实锁屏验收。
