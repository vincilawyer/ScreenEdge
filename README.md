# 跨屏边缘 · ScreenEdge

一个原生 macOS 菜单栏小工具：在屏幕边缘显示细线，帮助找到鼠标能跨向另一块屏幕的位置。继续使用苹果自带的扩展屏和通用控制。

## 使用

1. 打开 **跨屏边缘.app**，菜单栏会出现双屏图标。
2. **扩展屏**：保持“自动标记扩展屏交界”开启。彩虹渐变细线标记真正相邻且重叠的边缘；插拔显示器、改变排列或唤醒后自动刷新。镜像屏幕不作为跨屏通道。
3. **通用控制（另一台 Mac / iPad）**：点“添加标记”，选择本机屏幕、边缘和目标名称，调整起点与终点。暖色渐变细线实时更新。左右边的百分比从上往下计算；上下边从左往右计算。
4. 对照系统“显示器 → 排列”设置标记。手动标记不能检测远端设备是否连接，设备断开时可在菜单栏关闭那条标记；排列变化后需要重新调整。另一台 Mac 如需显示返回方向的提示线，也要运行本应用；iPad 无法运行这个 Mac 应用。
5. 线条默认常显，可改为“仅在鼠标靠近边缘时显示”。支持 2–8 点粗细。“预览 4 秒”临时在各本机屏幕右侧显示示例线，不会保存为真实通道。
6. 设置自动保存。关闭设置窗口后工具仍在菜单栏运行；通过“退出跨屏边缘”关闭。登录启动默认关闭，需在设置中自行开启。建议先把应用放到长期保留的位置，再开启登录启动。

## 渐变色如何对应

自动通道的两端使用同一组渐变色。左右相邻的屏幕从上往下渐变，上下相邻的屏幕从左往右渐变；颜色只铺在真正相接的那段边缘上。即使屏幕尺寸、缩放倍率不同，源屏幕某个位置的颜色也与目标屏幕相应进入位置的颜色对应。

手动通用控制标记在选定范围内渐变。如果要用两台 Mac 的颜色对照出入口，请分别设置实际通道的起止位置；应用不会改变系统的跨屏映射，手动范围设错时颜色不能代表真实出入口。

提示线穿透鼠标点击，不获取键盘焦点；应用不拦截、注入或移动键鼠，不更改显示器排列，不替代苹果通用控制。不请求辅助功能、输入监控或屏幕录制权限，不访问网络。

## 支持范围

- macOS 13+；当前交付构建为 Apple Silicon（arm64）。
- 普通扩展屏：使用公开的 NSScreen / CoreGraphics 坐标，自动绘制双向交界。
- 通用控制：当前没有可靠的公开布局读取接口；本版采用手动标记，不解码系统私有配置，不宣称已检测到远端连接。
- 覆盖层设置为跨桌面和全屏辅助窗口。锁屏、独占显示和特殊系统界面由系统管理，不能保证覆盖。
- 此次本机使用临时签名，无 Apple Developer ID 公证。换机分发需自行签名/公证或从源码构建；无需关闭系统安全保护。

## 构建与检查

只需 Xcode Command Line Tools，无第三方依赖：

```sh
./scripts/build.sh
./scripts/test.sh
open "build/跨屏边缘.app"
```

输出在 `build/跨屏边缘.app`。默认构建 arm64，也可以指定 Intel 架构：

```sh
SCREENEDGE_ARCH=x86_64 ./scripts/build.sh
```

注意：架构选项会覆盖同一个构建产物，换机交付前应在目标系统测试。

在已登录的 macOS 图形会话中执行原生覆盖层检查（临时设置，不写入用户配置）：

```sh
"build/跨屏边缘.app/Contents/MacOS/ScreenEdge" --smoke-test
```

`--settings` 强制显示设置窗口。测试需要能连接 WindowServer；受限沙箱内可能无法读取显示器。

## 验证

- 39 项几何与配置检查：四个方向、错位、负坐标、部分重叠、镜像、角接触、间隙、一边对应多个屏幕、手动范围、无效范围、离线屏幕、配置序列化、渐变坐标和方向对应。
- 原生检查覆盖：覆盖层真实窗口位置、鼠标穿透、不可激活、全屏/桌面标志、主开关、方向切换、靠近模式、删除；当前两块真实显示器的对应坐标及不同长度渐变渲染采样。
- UI 实测覆盖：添加标记、方向和范围调整；实机从一块屏幕增加到两块时自动更新交界。
- 登录项未自动开启；跨设备通用控制的实际往返需按使用者系统排列校准。

## 项目来源与查找记录

本项目为本次需求独立编写，没有复制其他项目代码。检索 GitHub 后，未找到能直接满足“保留系统键鼠共享、只显示可跨屏边缘”的现成项目：

- [ShowyEdge](https://github.com/pqrs-org/ShowyEdge)：显示输入法颜色条。
- [JankyBorders](https://github.com/FelixKratz/JankyBorders)：给窗口描边。
- [MousePortal](https://github.com/ai-eks/MousePortal)：配置光标跳转通道。
- [Cursr](https://cursr.app/)：边界覆盖层在查询时仍列于 Upcoming Features。

这些项目只作为功能对照，并非本项目依赖。查询日期：2026-09-12。

## 保存位置与移除

用户设置存于应用的 `local.screenedge.app` 偏好域，不进入源码仓库。退出应用后即可移除 app；若已开启登录启动，先在应用中关闭。源码、构建产物和用户配置相互独立。
